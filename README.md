# FinTrack

A personal financial tracker mobile app built with React Native (Expo).

## Features

- **Expense Tracking**: Log personal and business expenses with categories
- **Budget Management**: Set monthly budgets by category with overspending alerts
- **Subscription Manager**: Track recurring subscriptions with cost normalization
- **Savings Goals**: Set targets, log contributions, and track progress with projections

## Tech Stack

- React Native (Expo) with TypeScript
- React Native Paper (Material Design 3)
- React Navigation (bottom tabs + stack navigators)
- Zustand with AsyncStorage persistence
- date-fns for date utilities

## Getting Started

```bash
npm install
npx expo start
```

Scan the QR code with the Expo Go app on your phone, or press:
- `i` for iOS simulator
- `a` for Android emulator
- `w` for web browser
